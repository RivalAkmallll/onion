# Onion UI Lab (Rust-hosted Dioxus 0.7 prototype)

This is NOT Onion-language code. It is a visual design experiment for a future Onion UI toolchain.

On Windows, from the `experiments/onion-ui-lab` folder:

```powershell
cargo run
```

Requires Rust toolchain and WebView2 runtime. Edit `assets/main.css` to customize colors, spacing, cards, layout, responsiveness. Rust UI is in `src/main.rs`.

Do not publish this example as a completed native Onion UI implementation.
